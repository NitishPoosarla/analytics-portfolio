# LinkedIn post — Project 06 (Software)

---

Unlabeled GitHub issues sit ~60% longer in the backlog than labeled ones. That's not
an opinion — it's measurable from the public GitHub API. 🛠️

I built an engineering-delivery analytics project (DORA-style flow thinking, analyst's
toolbelt):

→ Sampled 1,000 issues from pandas-dev/pandas
→ Measured open→close cycle time (median + P90) — the baseline your delivery reviews should track
→ Found triage pays: labeling-on-arrival shortens backlog age substantially
→ Found chatter costs: issues with 10+ comments resolve slowest — consensus is real time
→ Framed the KPI trio to publish weekly: median cycle / P90 cycle / share of open >180d

Why I love this project: it sets the evaluation baseline for AI-assisted triage. Any
"AI fixes your backlog" claim should first produce THIS chart as the comparison point.

Code + interactive dashboard in the repo (first comment).
