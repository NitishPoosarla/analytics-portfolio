# LinkedIn post — Project 09 (Management)

---

Overtime staff earn MORE on average — and quit at ~2.6x the rate of everyone else.
Workload, not wages, is the retention lever. That's the headline of a people-analytics
project built end to end. 👥

1,470 employees, public IBM HR dataset:

→ Overtime attrition ~2.6x the no-overtime rate (KPI card computes the exact ratio)
→ New hires (≤2 yrs) exit ~30% vs ~11% for tenured staff — the first 730 days own this
→ Interpretable attrition model (AUC on test recorded; no black boxes for people data)
→ Costed retention: targeted package for the ≥50%-risk cohort → positive ROI under
   conservative assumptions ($45k replacement, $3k package, 25% save rate)
→ And an ETHICS guardrail, written into the deliverable: aggregate dashboards only;
   no protected attributes in the model; AI narrates verified metrics and the
   individualized-decision question stays with humans

That last line is what separates analyst work from surveillance, and I refuse to
ship the latter.

Interactive dashboard + code in the repo (first comment).
